## 📖 About

ShtockFish is an open-source chess bot project.

The goal of the project is to create a chess engine and experiment with chess programming, algorithms, and game logic.

## 🚀 Features

- ♟️ Chess game logic
- 🤖 Computer chess bot
- 🧠 Move searching
- 📊 Position evaluation
- 💻 Open-source code
- 🔧 Still under development
